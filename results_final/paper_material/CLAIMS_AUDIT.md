# Claims Audit

| Claim | Supported? | Evidence | Safe wording |
|---|---|---|---|
| Unified physical + digital detection | **Partially — as an implementation, not as novelty** | `xuad/data/attacks.py` (6 synth classes + adversarial spanning both families), `xuad/models/xuad.py` (one 8-way head) | "X-UAD performs unified physical and digital attack detection" — safe. "X-UAD is the first unified physical+digital detector" — **unsupported and false**; `yu2024unified` predates it. |
| Explainability | **Yes, with a specific mechanism, not "explainable" in general** | `xuad/xai/reasoning.py::GroundedReasoner` (rule-guarded, record-only text generation), `MLLMReasoner.verify()` (audits LLM output against the record) | "X-UAD generates explanations exclusively from a typed, verifiable evidence record, with zero hallucination by construction in the rule-based back-end" — safe. "First explainable FAS system" — **unsupported**; VLM-based forensic explanation (`huang2024ffaa`, `guo2025m2f2det`) predates it. |
| Uncertainty estimation | **Yes** | `xuad/models/heads.py::EvidentialHead` (Dirichlet, decoupled direction/magnitude), mean vacuity reported per model in every `results_*/*.json` | "X-UAD estimates calibrated (Dirichlet-evidential) uncertainty" — safe. Do not claim the uncertainty channel is reliable in every setting — the earlier campaign's `PROJECT_STATE.md` records it failing/anti-correlating on 2 of 4 unseen-attack folds; not re-tested this session. |
| Localisation | **Yes, for the best single model; not for the ensemble** | `results_region_pooled_detached/xuad_P1_regionpool_detached.json` (`loc_IoU=0.8887`, `loc_Dice=0.9349`) | "The best single X-UAD model localises attack evidence at 0.889 IoU" — safe. Do not attribute localisation numbers to "the final ensemble" — it has no native localisation output (`LIMITATIONS.md` #8). |
| Adaptive (quantum-inspired) transformer attention | **Yes, mechanism verified; "quantum" needs explicit qualification** | `xuad/models/aqa.py::AdaptiveQuantumAttention`, `GivensCircuit` — real-valued, classically computed | "a classical, simulated attention channel inspired by the Born rule of quantum measurement, adaptively gated per head against standard dot-product attention" — safe. Any wording implying quantum hardware, quantum speedup, or quantum advantage — **unsupported and must not be used**. |
| Novelty (general) | **Only the specific integration, not any single component** | `NOVELTY_AND_RESEARCH_GAP.md` | Use the "strongest defensible novelty statement" in that document verbatim; do not claim novelty for unified detection, ViT-for-FAS, or explainability individually. |
| State-of-the-art (SOTA) | **No** | No external head-to-head comparison was performed this session; `COMPARISON.md` (earlier campaign, different dataset) shows X-UAD trailing the best convolutional baseline (CDCN++) on raw accuracy/ACER even there | **Do not claim SOTA.** Safe: "we report results on our own constructed benchmark; no comparison to an external state-of-the-art system was performed." |
| Generalization (to real/external data) | **No** | `PROJECT_STATE.md`: no experiment has been run on a real corpus; adapters exist but are only regression-tested against synthetic mock fixtures. Unchanged by this session. | **Do not claim generalization.** Safe: "generalisation to captured, real-world attack data has not been evaluated." |
| 96.24% accuracy (final ensemble) | **Yes, independently re-verified** | `results_final/xuad_final_ensemble_metrics.json`, re-verified from raw `_pred.npz` arrays in this task (96.239583%, 361 errors) | "A 7-model probability-averaging ensemble of already-trained X-UAD variants reaches 96.24% 8-class test accuracy on our benchmark" — safe, with the ensemble-methodology caveat (`LIMITATIONS.md` #6) disclosed nearby. |
| 99.99% AUC | **Yes** | `results_final/xuad_final_ensemble_metrics.json` (`AUC: 99.99`) — binary attack-vs-bonafide AUC, not 8-way accuracy | State explicitly this is the **binary** (attack vs. bonafide) AUC, not an 8-class metric, to avoid the reader conflating it with the 96.24% 8-way figure. |
| 0.50% ACER | **Yes** | `results_final/xuad_final_ensemble_metrics.json` (`ACER: 0.5`), threshold derived from the validation ensemble (not test) — `results_final/FINAL_RESULTS_REPORT.md` §3 | Safe as stated, with the threshold-source note nearby for rigor. |
| "MAYA" / "One Model, All Attacks" / "I-FAS" as related work | **Not supported — no citation exists in this project** | Not present in `paper/refs.bib`; not found in any file inspected this session | **Do not cite with invented bibliographic details.** Locate and verify the real citations before including these works, or omit them. |
| "Recent VLM-based unified FAS work" beyond FFAA/M2F2-Det | **Partially — only two specific works verified** | `huang2024ffaa`, `guo2025m2f2det` in `paper/refs.bib` | Cite only these two unless additional real citations are located; do not gesture at "recent work" without a specific, verifiable reference. |
| X-UAD single-model accuracy 94.58% | **Yes, independently re-verified this session** | `results_region_pooled_detached/xuad_P1_regionpool_detached.json`; re-verified via raw prediction arrays in the emergency analysis and final-ensemble tasks | Safe as stated; pair with the honest caveat that this specific result is a "mixed" result (bonafide recall regressed slightly, accuracy gain not independently significant vs. the prior reference) — `ABLATION_ANALYSIS.md` §8. |
| X-UAD architecture matches the earlier campaign's `COMPARISON.md`/`RESULTS.md` numbers (ACC=94.53%, ACER=1.46%, loc IoU=77.8%, etc.) | **No — different campaign, different dataset composition** | `PROJECT_STATE.md` describes a 29,400+4,900-sample, 10-epoch-budget build; this session used a 29,400+4,200-sample, 12-epoch-budget build | **Do not merge these numbers with this session's results.** If referenced at all, label explicitly as "earlier campaign, not reproduced this session." |
